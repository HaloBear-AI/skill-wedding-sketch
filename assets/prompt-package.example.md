# 婚礼方案手绘板 · 生图提示词包

- 图内语言 `zh` · 参考适配 `通用` · 优先尝试 `full`。每次只复制一个版本的代码块。
- 画幅选择 `3:4` 竖版，例如 1536 × 2048。生成数量设为一，选择可用的高细节质量。平台只提供近似比例时等比补纸边，并复核底带。
- 有图像输入时附原始参考图，并采用相应参考图角色。纯文本接口用解析内容。平台有专用负面提示框时可把第 10 节移入该字段。
